# Documentation Hub

## What this folder does

This folder is the knowledge center for architecture decisions, implementation paths, and operational guidance.
It explains the why and how behind the repository patterns so teams can adopt components consistently.

## Folder description and details

- `golden-paths/`: prescriptive implementation guides for core capabilities.
- `guides/`: deep-dive reference material and thematic guidance.
- `decisions/`: ADRs documenting architecture and technology choices.
- `model-cards/`: model card examples and documentation artifacts.
- `local-setup.md`: local development and environment setup instructions.

## How to use this as an individual component

1. Start with `docs/golden-paths/` for step-by-step implementation.
2. Use `docs/decisions/` to understand non-obvious architectural tradeoffs.
3. Reference `docs/guides/` for best practices before introducing new patterns.
4. Keep documentation aligned with code changes by updating related guides/ADRs.
5. Use `docs/model-cards/` as templates or examples for model governance artifacts.

## Inputs and outputs

- Inputs: repository changes, architecture updates, new operational lessons.
- Outputs: actionable guidance, decision traceability, and onboarding-ready documentation.
